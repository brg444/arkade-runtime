# Security policy

Report suspected unauthorized signing, program substitution, tenant-isolation
failures, ledger rollback, transaction-verification defects, recovery bypasses,
and private-key exposure through a [private GitHub security advisory](https://github.com/brg444/arkade-runtime/security/advisories/new).

Include the affected commit, reproduction steps, deployment assumptions, and
potential fund impact. Keep exploits, credentials, private keys, and sensitive
user data out of public issues. General defects without a security impact can
use the public issue tracker.
